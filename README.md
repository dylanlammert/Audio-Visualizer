Developers: [Madeline Olive](https://github.com/mo2288), [Anna Warring](https://github.com/awarring26), [Ethan Brown](https://github.com/Ethan-B319), [Peyton Farrant](http://github.com), [Dylan Lammert](https://github.com/dylanlammert)

### Libraries
1. Minim by Damien Di Fede and Anderson Mills

### Project Description
This audio visualizer can switch between 4 different visualization modes. There is also a section for audio manipulation.

### Getting Setup
Donwload the required libraries shown above. On start up you will see the main screen with a file launcher on the left bar. Click the text that says "Start a new project..." this will open up a system file explorer, select a folder you wish to access that contains the audio files. 

While the folder is open you can select different files to be loaded into the visualizer.
